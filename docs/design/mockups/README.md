## Design context

The source response describes soft lavender-to-blue backgrounds, opaque white
microcomponents, dark text, deep-violet primary actions, explicit selected states,
and consistent headers and chat composers. These are static UX concepts. Values
shown in vehicle, financing, or appointment screens are illustrative design content;
the application must use the researched data and implemented behavior.

The app’s Mazda emblem comes from page 1 of the locally saved [2027 CX-5 specification deck](https://news.mazdausa.com/download/27MY+CX5+Spec+Deck+FINAL.pdf).
